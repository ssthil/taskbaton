hit 100%?

taskbaton checkpoint  saves your state mid-session.
Switch to another tool — pick up from a draft, not a blank page.
$ taskbaton checkpoint
✓ checkpoint saved at 22:14  •  stage: feature/auth  •  open 47 min
  run taskbaton review to add notes · seal to finalize
